# 运行状态与状态标签

## 运行状态

- 设备或产线的运行状态写成「圆点 + 文字」，不做成标签：运行中用品牌绿圆点（亮色 `highlight-ink`，暗色 `highlight`），停机、故障用对应状态色圆点。
- 设备运行信号与业务流程状态分开：作业单的「进行中」用下方 `AntTag`，不套用设备运行绿点。

## 状态标签

- 直接使用 `@tier0/ui` 的 `AntTag` 及其样式、主题依赖，来源为 `packages/ui/components/ant-tag/index.tsx` 与 `style.module.scss`。不手写标签，不用 `Badge` 或普通胶囊替代。
- 默认 `bordered={false}`，圆角由组件保持 4px；沿用组件的字号、内边距、颜色与截断，不覆盖成全圆角、实底或自配透明度。只有确有描边需求时才显式设 `bordered`。
- 语义主题：中性、待处理用 `default`；进行中、信息提示用 `blue`；已完成、成功用 `success`；警告用 `warning`；失败、严重告警用 `error`。`fx-green` 只用于品牌语义，不作为所有业务状态的默认色。
- 组件的语义色使用对应色阶 50 底、600 字；`default` 是 grey-50 底与 black-500 字，`fx-green` 是 fx-green-50 底与 fx-green-700 字。以组件样式为准，不另写颜色映射。
- 文案只写状态本身，主题颜色与文字已表达状态时，不再加同义圆点或图标。`Badge` 仅用于通知数量等计数标记。

```tsx
<AntTag theme="default">待处理</AntTag>
<AntTag theme="blue">进行中</AntTag>
<AntTag theme="success">已完成</AntTag>
```

## 窄屏与长文案

- 短状态保持单行，表格状态列预留完整标签的空间，不把标签挤窄来强行塞下整张表；窄屏让表格容器横向滚动。
- 长分类标签限制在所在容器宽度内，沿用 `AntTag` 的省略样式；字符串子项会生成原生 `title`。需要触屏或键盘查看完整内容时，用可聚焦的详情入口或组件库提示补充，不能仅依赖悬停。
- 多个标签可在父容器换行并使用间距 token；不缩小标签字号，不裁掉关闭按钮。
