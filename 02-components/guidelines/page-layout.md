# 页面布局

- 布局从任务出发：先确定这一页最重要的信息和操作，让它们在第一屏、在视线起点；再安排次要内容。不为对称或填满空间加区块。
- 常见结构是左侧导航 + 右侧工作区。侧栏可以用浅灰（`subtle`）底、工作区用白底，把注意力引到右侧。顶栏只在承载内容时出现，保持窄。
- 层级用间距表达：同一组里的并列元素间隔 `group-item`，组与组之间间隔 `group`。例如一组指标卡之间用 `group-item`，指标卡组和旁边的告警列表之间用 `group`；所有区块等间距会让分组消失。
- 并排的区块高度由各自内容决定，不为了和旁边对齐而拉高、留出大片空白；需要对齐时用真实内容填满，否则顶部对齐即可。

## 侧栏与窄屏适配

- 侧栏统一使用 `shell.sidebar` 240px / `shell.sidebar-collapsed` 64px；在同一个 `SidebarProvider` 下组合 `Sidebar` 与 `SidebarInset`，不重复计算左偏移。
- 工作区及其子容器允许收缩（`min-width: 0`）；栅格工作列用 `minmax(0, 1fr)`。不能用 `100vw` 再加侧栏宽度。
- 小于 `breakpoint.md`（768px）采用组件自带抽屉，关闭后工作区占满宽度；保持导航打开入口、关闭与焦点返回行为。
- 标题操作和筛选控件可换行，指标卡按可用宽度减列；表格的横向滚动限于自身容器，不裁掉首列、末列操作或状态标签。
- 仅保留有结构职责的分隔线；标题和筛选栏不用额外横线；升级卡片与底部账户之间允许一条分隔线，页签和表格边界不重复描边。
- 验收至少覆盖桌面、768px 两侧和手机宽度，并检查展开、收起、抽屉打开与关闭：页面无横向溢出，标题与表格不被遮挡，头像和通知可用。
