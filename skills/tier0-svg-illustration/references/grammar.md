# Grammar · spot only

## 网格

- 坐标优先 4 的倍数  
- 模块宽高常见 40 / 48 / 64 / 80  
- 线宽 1；accent 描边最多 1.2

## 文字预算

```
允许：SLOT / IN / OUT / qty 示意（短）
禁止：段落、双栏说明、STATUS 顶栏、Fig 长句、中文大标题
```

需要可访问性时用 `<title>` / `<desc>`，不要画进画面。

## 色用法

```
80% 黑底 + 深灰面板
15% 灰线/灰字
5% #B2ED1D（一个高亮节点或一条主曲线）
```

## 元素

1. **货架/等角块** — 平行四边形 stroke，同色系填充极暗  
2. **小窗** — 顶条可选三圆点（灰），内容区极少字  
3. **折线** — 单主线 + 弱面积  
4. **glyph** — 仅作底部分隔一行，勿铺满
