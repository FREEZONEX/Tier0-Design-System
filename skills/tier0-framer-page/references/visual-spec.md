## 1. Token

| Token | 值 | 用途 |
|-------|-----|------|
| `--t0-fg` | `#050B14` | 标题、主文字、黑底态（手机端选中 chip、当前页码、邮件按钮） |
| `--t0-fg2` | `#343434` | 次级正文 |
| `--t0-muted` / `--t0-faint` | `#62666B` / `#8A8D90` | 说明、标签、计数 |
| `--t0-surface` / `--t0-subtle` | `#F8F8F7` / `#F2F2F1` | 版本信息框、展开行、侧栏选中、分段控件底 |
| `--t0-border` / `--t0-input` | `#EBEBEB` / `#E2E2E2` | 卡片 / 输入框 1px 描边 |
| `--t0-lime` | `#B2ED1D` | 主 CTA、计数徽标、帮助卡图标块 |
| `--t0-lime-50/100/200` | `#F7FDE8` / `#EEFAD0` / `#DCF797` | 状态 chip 底、提示条图标底、帮助卡底与描边 |
| `--t0-lime-700/900` | `#7EA815` / `#48640C` | 加固类圆点 / 浅绿底上的文字 |
| 圆角 | `4px`（嵌套 `3px`） | 全部组件 |
| 阴影 | `none` | 全部组件 |
| 焦点 | 2px 近墨 outline；输入框 focus = 近墨边 + 4px 亮绿光晕 | 键盘可见 |

亮绿是 **面 / 按钮 / 徽标**，不做正文字色；浅底上的绿字用 `#48640C`（或品牌 `#73B200` 大字）。

## 3. 页面结构（桌面）

```text
┌ Hero ───────────────────────────────────────────────┐
│ H1                                   [✉ REPORT …  ↗] │  ← 方形亮绿 CTA（mailto）
│ 一行描述                                              │
│ [ⓘ 更新方式说明  一句话说明 …            查看说明 ↓ ] │  ← 提示条（白底细边），点「查看说明」滚到说明区
└──────────────────────────────────────────────────────┘
┌ 侧栏 240px（sticky）┐ ┌ 主卡片（1px 边，无阴影）────────────┐
│ 记录类型             │ │ 公告列表                  [14 条记录] │
│ ● 全部记录      [14] │ │ [🔍 搜索 … /]            [排序 ▾]    │
│ ● 产品安全修复    7  │ │ 显示 1–10 条，共 14 条    ⇕ 全部展开  │
│ …                    │ ├────────────────────────────────────┤
│ 产品 / 环境           │ │ 2026 年 9 月  3 条                   │  ← 月份分组
│ [全部|Enterprise|Cloud]│ │ 9 月 20 日  ● 分类 · 组件   [✓已修复] ⌄│
│ ┌ 发现安全问题？ ┐    │ │ [Enterprise] 标题                    │
│ │ 浅绿底 + 黑按钮 │    │ │            两行摘要…                 │
│ └ 发送邮件      ┘    │ │            [受影响 | 修复 | 升级]灰框 │
└──────────────────────┘ │ 第 1/2 页        ‹ 上一页 [1] 2 下一页 › │
                         └────────────────────────────────────┘
说明区：H2 + 一句 intro + 4 张图标卡（受影响 / 修复 / 升级包 / 依据）
```

### 组件细则

- **分类导航**：圆点区分类型（产品修复 = 近墨、组件更新 = 灰、加固 = `#7EA815`、验证 = 空心环、全部 = 四色饼）；选中 = 浅灰底 + 亮绿计数徽标；数量随产品筛选和搜索 **联动**，为 0 时置灰
- **产品切换**：分段控件（不用下拉），选中白底 + 1px 边
- **列表行**：左列日期（`Sep 20` / `9 月 20 日`）+ Mono 产品标签（Cloud 用浅绿标签）；右侧状态 chip（已修复 = 浅绿底 + 勾；已验证 = 灰底 + 徽章）+ 30px 展开箭头
- **展开详情**：摘要变全文；版本框变白底细边；下方白卡分两组事实（版本与升级 → 范围 / 影响 / 处理 / 时间 / 依据），升级步骤用浅绿编号圆点；底部「复制链接」按钮内反馈「已复制」
- **翻页**：卡片底部浅灰条；当前页近墨底白字；只有 1 页时整条隐藏
- **帮助卡**：浅绿底 `#F7FDE8` + `#DCF797` 描边 + 亮绿图标块 + 近墨 `mailto` 按钮
- **说明卡**：白底细边，图标块浅灰，hover 只变边框色（不位移、不加阴影）

## 4. 响应式（container query，按组件自身宽度）

| 档 | 条件 | 变化 |
|----|------|------|
| 桌面 | ≥1024 | 侧栏 + 主卡片两栏，侧栏 sticky（top = Nav offset） |
| 平板 | ≤1023 | 侧栏拆开：分类变横排 chip（自动换行，选中黑底）→ 产品分段（≤360px）→ 主卡片 → 帮助卡变横条；说明卡 2 列 |
| 平板 730 | ≤820 | Hero 竖排、CTA 移到描述下；列表行变两层：首行 日期 + 产品 + 状态 + 箭头，下方标题 / 摘要 / 版本框 |
| 手机 390 | ≤560 | 边距 ≤16px；CTA 满宽；分类 **2 列平铺**（全部独占一行）；产品分段满宽；主卡片左右贴边去圆角；版本框 2 列；翻页只留 上一页 / 下一页 + 页码文字；帮助卡竖排；说明卡竖排（图标左、文字右） |

整页 **不得出现横向滚动区域**。

## 5. 删除清单（拿到旧稿先删）

- 每个区块上方的 Mono 英文 eyebrow（`■ ADVISORIES & UPDATES`、`01 / AFFECTED`）与装饰小方块
- 与 H1 重复的区块标题、列表表头
- 记录底部的编号串（`TIER0 / 日期 / CATEGORY`）、「展开查看详情」提示、「回到顶部」
- 不会展开的假下拉箭头 `⌄`
- 统计卡 / 语言切换 / Hero 背景图形（评审中均被移除）

## 6. 交互基线

计数联动筛选 · 筛选时保留已展开项 · 全部展开 / 收起 · 单页隐藏分页 · 翻页仅在列表已滚出视口时回滚 · `/` 聚焦搜索（输入中不抢键）· `#record-<id>` 深链自动翻页并展开 · 复制链接失败时按钮内提示
