# Tier0 × Lieflat color bridge

When the parent task is a Tier0 deliverable (website / deck / print / product evidence page):

1. Lock **one** colour system for the whole chart HTML (Lieflat rule).
2. Prefer **custom** palette (not default Mono cream `#F0EFEB`) unless user asks Mono:
   - ink / text: `#050B14`
   - accent signal: `#B2ED1D` (structure markers only; not body text on white)
   - accent text on white: `#73B200`
   - paper: `#FFFFFF` or soft `#F7F8F9`
   - muted: `#73777D`
   - border: `#EBEBEB` / `#CDCED0`
3. Fonts: IBM Plex Sans / Mono (override Mono stack in the HTML shell when embedding into Tier0 pages).
4. Still follow Lieflat template selection (`catalog.md` → gallery card → script block). Do not invent chart geometry.
