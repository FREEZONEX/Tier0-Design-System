# User-provided architecture references

This folder reserves the original screenshots supplied by the user for future diagram work.

At the time this index was created, the conversation attachments were available for visual interpretation but were not exposed as copyable local files in the workspace. Their intended filenames, relationship grammars, and permitted uses are captured in `reference-manifest.json`.

When the original image files are attached or placed in the workspace, copy them here using the matching `suggestedFilename`. Treat them as visual/structural references—not as files to trace, recolor, or publish verbatim.
