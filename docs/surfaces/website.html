  1. 01

    拿到规范与 token

    GitHub：surfaces/company-website/ + tokens/website.css。可选对照 docs.tier0.app 的信息架构，但视觉以 Pricing / Builder 为准。

  2. 02

    在 Agent 中锁定场景

    打开本仓库或粘贴路径。明确「company-website / 编辑风长页」；标题用 IBM Plex Sans，禁止 Inter 作品牌标题，禁止 startup 巨型 CTA Hero。

  3. 03

    用 Prompt 生成页面

    写清受众、章节顺序、要挑的关键词。主 CTA 用 #B2ED1D 绿底近墨字；白底挑词用 #73B200。

  4. 04

    验收与上线

    对照本页组件卡与线上官网：细边框、4px 圆角、■ Mono 标签。通过后合入营销站点或静态托管。
