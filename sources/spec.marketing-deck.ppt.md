# Tier0 Masterdeck — PowerPoint 设计系统规范

> **版本**：1.5  
> **依据**：`26.01.14-Tier0 Masterdeck.pptx`（主题 `theme1.xml`、幻灯片母版 `slideMaster1.xml`、版式 `slideLayouts`、全稿 XML 抽样）+ 全稿 PDF/PNG 导出视觉核对（深色章节页标题字重以画面为准）。

---

## 1. 设计原则（PPT 语境）

- **双模态**：**深色章节页**（节奏断点、大字号标题）与 **白底内容页**（信息密度、图表与列表）交替，形成路演节奏。  
- **工业编辑感**：少装饰、多结构；强调色只做「标点」，不做满屏荧光。  
- **字体分工**：**封面**主展示字用 **Poppins**（拉丁为主）；**深色章节页**大标题用 **Tektur Regular**（拉丁为主）；**白底内容页**顶栏页面标题 **IBM Plex Sans Medium**（拉丁）/ **IBM Plex Sans SC Medium**（简中），**不用 Poppins**；**拉丁正文**用 **IBM Plex Sans**，**东亚与简体中文**一律 **IBM Plex Sans SC**（与西文同档 Regular / Medium / SemiBold 等配对）；页脚/技术感细字 **IBM Plex Mono**。  
- **字体白名单**：全稿**仅允许** **Tektur、Poppins、IBM Plex Sans、IBM Plex Sans SC、IBM Plex Mono** 五族；其中 **IBM Plex Sans SC** **专用于东亚与简体中文字形**，不得改用其他中文字体；拉丁与基本标点用 **IBM Plex Sans**；母版与样式中须显式指定 **拉丁 / 东亚** 字体槽，避免系统回退到非白名单字体。
- **品牌呈现（Tier0 only）**：幻灯片画面与文案**仅呈现 Tier0**（Logo、产品名、版权）。**禁止**出现母公司 **FREEZONEX** 字样、Logo、页脚条或「FREEZONEX's …」类归属表述。历史母版若仍含母公司页脚条，改版时应删除。
- **重点标题绿色（按底区分）**：**深色底**挑词 / 重点标题用 **`#B2ED1D`（accent1）**；**白底** eyebrow、页内挑词、KPI 数字、流程卡小标题等用 **`#73B200`（accent2）**。
- **结构标记（白底亦用亮绿）**：项目符号方块、卡片**顶边描边**、时间轴结构线等仍用 **`#B2ED1D`（accent1）**，不用 `#73B200`。CSS：`--ppt-emphasis-on-dark` / `--ppt-emphasis-on-light` / `--ppt-accent-marker`（见 `tokens/deck.css`）。
- **UI 图标**：幻灯片内小图标使用 **[Lucide](https://lucide.dev)**（描边 1.75）；能力栅格卡见 `tokens/icon-card.css` + [icons-lucide.md](../foundations/icons-lucide.md)。主视觉等轴测插画仍按 §5.5，不用 Lucide 替代。

## 2. 配色系统（必须绑定主题色）

以下配色以 **`ppt/theme/theme1.xml` 配色方案「自定义 1」** 为主干在 PowerPoint 中维护；其中 **品牌蓝固定为 `#1D77FE`**（含链接与 `accent4` 语义），若源文件曾为其他蓝 HEX，**改版时以 §2.1 为准**写回主题。应通过 **设计 → 变体 → 颜色 → 自定义颜色** 与下表对齐，禁止仅在手绘形状上吸色脱离主题。

### 2.1 主题色板（Theme colors）

| 主题槽位 | HEX | 在稿中的典型用途 |
|-----------|-----|------------------|

| **强调色 2（accent2）** | `#73B200` | **白底**上的重点标题 / eyebrow / KPI 数字；图标填充、渐变第二站 |

## 3. 字体与字重体系

### 3.1 主题字体方案（母版 XML 可能仍为历史 `fontScheme name="freezonex"`，**画面不得出现该字样**）

| 角色 | 字体 | 说明 |
|------|------|------|
| **Major（标题，拉丁）** | **Poppins SemiBold** | 对应母版 `+mj-lt`；封面等 |
| **Major（标题，东亚）** | **IBM Plex Sans SC SemiBold** | 对应母版 `+mj-ea`；封面/标题中简中与东亚字符 |
| **Minor（正文，拉丁）** | **IBM Plex Sans** | 对应 `+mn-lt`；英文、数字、拉丁标点 |
| **Minor（正文，东亚）** | **IBM Plex Sans SC** | 对应 `+mn-ea`；**简体中文及东亚文本**（Regular / Medium / SemiBold 等与西文同级配对） |

**允许的字体族名**：`Tektur`、`Poppins`、`IBM Plex Sans`、`IBM Plex Sans SC`、`IBM Plex Mono`。其中 **IBM Plex Sans** 与 **IBM Plex Sans SC** 为 **拉丁 / 东亚分栈**，字重档位一一对应（如 Medium 在西文用 Sans、在中文用 Sans SC）。

> **母版操作**：在 **幻灯片母版 → 字体 → 自定义字体** 中，将 **东亚语言字体** 设为 **IBM Plex Sans SC**（与 **拉丁文字体** 的 **IBM Plex Sans** 配对），避免仍指向历史主题中的其他东亚字体。

### 3.2 母版 `txStyles` 默认值（`slideMaster1.xml`）

PowerPoint 中 **幻灯片母版 → 字体** 应反映下列层级（`sz` 单位为 **百分之一磅**，下表已换算为 **pt**）。

| 样式 | 默认字号 | 字色 | 拉丁 / 东亚字体 |
|------|-----------|------|-------------------|
| **标题样式（titleStyle）** | **44 pt** | `tx1`（`#050B14`） | `+mj-lt` → Poppins SemiBold；**`+mj-ea` → IBM Plex Sans SC SemiBold** |
| **正文 1 级（bodyStyle lvl1）** | **28 pt** | `tx1` | `+mn-lt` → IBM Plex Sans；**`+mn-ea` → IBM Plex Sans SC** |
| **正文 2 级** | 24 pt | `tx1` | 同上 |
| **正文 3 级** | 20 pt | `tx1` | 同上 |
| **正文 4–9 级** | 18 pt | `tx1` | 同上 |
| **页脚 / 日期 / 幻灯片编号占位** | **12 pt** | `tx1` + **亮度 +82% tint**（浅灰） | 继承 minor；东亚若出现中文脚注，仍用 **IBM Plex Sans SC** |

**字距**：母版 `defRPr` 普遍带 `kern="1200"`（约 **0.12 pt 级**字距微调），标题与列表保持一致即可。

### 3.3 版式级标题默认值（与母版叠加）

| 版式（`slideLayout`） | 标题占位默认字号 | 备注 |
|------------------------|------------------|------|
| **标题幻灯片**（`type="title"`） | **居中主标题 60 pt** | `ctrTitle`；副标题占位内多级 **24 → 20 → 18 → 16 pt** |
| **节标题**（`type="secHead"`，中文名「节标题」） | **60 pt** | 底部对齐 `anchor="b"`，适合章节大标题 |
| **内容与标题 / 图片与标题**（`objTx` / `picTx`） | **32 pt** | 左区小标题条 |

### 3.4 用途与字重（新稿）

**规范（新稿）**：

| 用途 | 字体 | 字重 | 备注 |
|------|------|------|------|
| **封面**主标题（类型 A） | Poppins | **SemiBold 600** | 仅封面；可拆词上 accent1 |
| **白底内容页**页面标题（顶栏一行） | **IBM Plex Sans** / **IBM Plex Sans SC** | **Medium 500** | 拉丁用 **Sans**，简中用 **Sans SC**；**32 pt** 起，可至 **34–40 pt** 仍保持 Medium；**不**改用 Poppins |
| 深色背景章节 / 过渡页大标题 | **Tektur** | **Regular 400** | 黑底大标题；勿用 Bold 冒充 |
| 白底页 eyebrow / 小节条 | **IBM Plex Sans** / **IBM Plex Sans SC** | **Medium** | 字色 **accent2（`#73B200`）**，**18–24 pt** |
| 正文 / 要点 | **IBM Plex Sans** / **IBM Plex Sans SC** | **Regular 400** | 常见 **12–16 pt**；**拉丁 Sans、东亚/中文 Sans SC** |
| 强调行内词 | **IBM Plex Sans** / **IBM Plex Sans SC** | **SemiBold / Italic** | 慎用斜体大段 |
| 页脚版权 | IBM Plex Mono | **Regular** | 常见 **10–12 pt**、灰色 |

### 3.5 字号阶梯（内容页推荐）

以下与母版、版式及导出视觉对齐，**允许 ±2 pt** 以适应中英混排与行数。

| 层级 | 字号 | 字重 | 典型场景 |
|------|------|------|----------|
| **L0 封面主标题** | **54–72 pt** | Poppins SemiBold | 封面「TIER 0」级；可拆词上色 |
| **L1 章节标题** | **48–60 pt** | **Tektur Regular**（深底） | 深色过渡页；浅底节标题用 **IBM Plex Sans Medium / IBM Plex Sans SC Medium**，不用 Poppins |
| **L2 页面标题（白底内容页）** | **32–40 pt** | **IBM Plex Sans Medium / IBM Plex Sans SC Medium** | 顶栏单行；**禁止** Poppins；中文须 **Sans SC** |
| **L3 小节 /  eyebrow** | **18–24 pt** | **Sans / Sans SC**、Medium、**accent2（`#73B200`）** | 白底页；中文用 **Sans SC** |
| **L4 正文** | **14–16 pt** | Regular | 项目符号正文 |
| **L5 注释 / 图表标签** | **10–12 pt** | Regular | 图内标签、脚注 |
| **L6 页脚** | **10–12 pt** | IBM Plex Mono | `Copyright © 2026 Tier0…` |

**超大数字展示**（如 KPI）：稿内曾出现 **48–115 pt** 单数字，保留为 **KPI 专用样式**，勿用于句子标题。

### 3.6 行距与段落

- 母版标题样式：`lnSpc spcPct="90000"` → 约 **0.9 倍行距**（紧排标题）。  
- 多处正文文本框：`spcPct val="120000"` → **1.2 倍行距**（列表可读性）。  
- **规范**：正文列表统一 **1.2**；单行大标题可用 **0.9–1.0**。

## 4. 幻灯片类型（版式）与章节样式

### 4.1 类型 A — 封面（深色 + 品牌主视觉）

- **背景**：`#050B14`（`tx1`）+ 斜向点阵/细线 + **单条 accent1 对角线**（可选）。  
- **主标题**：白 + **accent1 挑词**（如「0」或关键词）。  
- **副标题**：白或浅灰，**20–24 pt**，Regular。  
- **Logo（可选）**：左下 **Tier0** wordmark（如 lime 反白 SVG），**无**母公司条形色块。  
- **右侧**：等轴测 / 3D 模块插画（**accent1**、**`#1D77FE`（可调透明度）**、白、深灰组合）。

### 4.2 类型 B — 深色章节过渡页（「呼吸」页）

- **背景**：同类型 A 全屏深底（`schemeClr tx1`）。  
- **主文案**：**Tektur Regular**，**白**，**极大字号**（建议 **≥ 48 pt**，常用两行长标题）。  
- **装饰**：低对比网格；避免再叠大块 accent1 底，防止投影糊成一团。  
- **页脚**：左下 **10–12 pt** 灰字版权（与 §5.1 一致），**无**母公司页脚条。

### 4.3 类型 C — 白底标准内容页（标题 + 正文 / 图）

- **背景**：`#FFFFFF`。  
- **顶区页面标题**：**IBM Plex Sans Medium**（拉丁）/ **IBM Plex Sans SC Medium**（简中），默认 **32 pt**（与版式 `objTx`/`picTx` 左栏标题一致）；信息较多时 **34–40 pt** 可略放大，**字重仍为 Medium**，不改为 SemiBold/Bold、不换成 Poppins。  
- **Eyebrow**：**accent2（`#73B200`）**，**18–24 pt**，**IBM Plex Sans Medium / IBM Plex Sans SC Medium**，可与章节序号「01 / 02」同排。  
- **页标题内挑词**（若有）：同色 **accent2（`#73B200`）**；正文与未强调标题用 `tx1`。  
- **正文**：**14–16 pt**，`#050B14`，行距 **1.2**；项目符号使用 **方点**（**`#B2ED1D` / accent1**，非 `#73B200`）。  
- **右栏插画**：**细线等轴测 + accent1 局部填色**，线稿为主、绿色仅作结构高光。  
- **页脚**：左下 **10–12 pt** 灰字版权；可选右下页码 **10 pt**（**IBM Plex Sans** 或 **Poppins** 均可——页码不属于「页面标题」，不受顶栏仅 Medium 约束）。

### 4.4 类型 D — 信息图 / 时间轴 / 客户墙

- **背景**：白或极浅 `lt2` / 自定义浅绿洗 (`#E6F9B4` 低透明)。  
- **主结构色**：**accent1** 轴线 + **`#1D77FE`** 辅助对比（**仅用该蓝色的实色与透明度变化**，不用其他蓝）。  
- **小标题**：**IBM Plex Sans Medium / IBM Plex Sans SC Medium**，字色 **accent2（`#73B200`）** 或 **`tx1`**，保持 **一种强调策略**：**要么绿字标题 + 黑正文，要么黑字标题 + 绿数据**，避免全屏堆绿。

### 4.5 类型 E — 对比双栏（Before / After、Tier0 vs Traditional）

- 两栏可用 **浅绿洗 vs 浅灰洗** 区分，或 **accent1 浅底 vs 白底**。  
- 结论栏：**accent1 背景 + 深绿字** 或 **深底反白** 二选一，全稿统一。

### 4.6 版式与母版使用约定

| Office 版式类型 | 中文名 | 建议用途 |
|-----------------|--------|----------|
| `title` | 标题幻灯片 | 封面、封底 |
| `secHead` | 节标题 | **深色章节大标题**（优先套此版式再改背景） |
| `obj` | 标题和内容 | 标准左文右图 |
| `twoObj` | 两栏内容 | 双列要点 |
| `titleOnly` | 仅标题 | 过渡一句话 |
| `blank` | 空白 | 全插画或自定义排版 |

## 5. 组件与重复元素

### 5.1 页脚

- 文案：`Copyright © 2026 Tier0. All rights reserved.`（**不得**写 FREEZONEX）  
- **字体**：IBM Plex Mono **10 pt**；颜色 **tx1 + 高 tint** 或固定 **#99A1AA** 类中性灰。  

### 5.2 项目符号

- **项目符号与编号**：与正文分栈一致——**IBM Plex Sans**（拉丁）+ **IBM Plex Sans SC**（简中/东亚）（与 §3 白名单一致）。  
- **级别缩进**：遵循母版 `bodyStyle` 的 `marL` / `indent`（一级 **-0.25"** 悬挂类结构）。

### 5.3 形状与线

- **通用描边**：图表分区线可用 **`#1D77FE`（常配合较高透明度）** 或 **中性灰**；强调框可用 **accent1** **1.5–2 pt**。  
- **圆角矩形与卡片级规范**（边距、白底对比、双栏、阴影等）：见 **§5.6**。

### 5.4 图表

- **系列色顺序建议**：accent1 → **`#1D77FE`**（可用透明度区分系列）→ accent3 → accent5 → lt2 深灰。  
- **背景**：白或透明，勿默认深灰底。

### 5.5 配图与插画风格

- **视角**：主视觉区统一 **等轴测（isometric）**；同一套透视与缩放比例，**避免**同屏混用「扁平描边 icon 语言」与「厚重 3D 渲染」两套语言。  
- **线稿**：结构线以 **`#050B14` 降低不透明度** 或 **中性灰** 为主；**全稿线宽一致**（约 **1 pt** 屏幕等价，勿同一页粗细不一）。  
- **上色**：**大面留白或透明**，仅在节点、箭头、数据条、设备高光处用 **accent1**；次要结构、连接、辅助设备可用 **`#1D77FE`（降低不透明）** 或 **lt2** 系浅填充。  
- **禁止**：强玻璃拟态、重投影、粗描边卡通化、与主题无关的彩虹渐变。  
- **屏内 UI / 小图**：若插画内含屏幕、仪表盘，内部柱线色 **遵循 §5.4 系列色顺序**；屏上标签字 **IBM Plex Sans / IBM Plex Sans SC 10–12 pt**（拉丁/中文分栈），不与页面正文抢层级。  
- **摄影与 Logo 墙**：实景或 Logo 密集区使用 **圆形或圆角矩形容器（圆角半径 4 pt）**裁切，外缘 **1–2 pt** 描边或细白边，避免直角大图硬贴。  
- **与版面关系**：配图区与左栏正文 **对齐纵向网格**；图块上缘不宜侵入顶栏 **IBM Plex Sans（拉丁）/ IBM Plex Sans SC（简中）Medium** 标题区。

### 5.6 卡片、色带与容器

- **白底上的白卡片**：卡片填 `#FFFFFF` 且画布为 `#FFFFFF` 时，**必须**二选一：**极浅灰描边**（`tx1` **约 8–12% 不透明**、**1 pt**）或 **极浅填充**（`lt2` `#EFECE0` 或 `#F7F7F5` 级），否则层次丢失。  
- **圆角**：全稿圆角矩形（含卡片、裁图容器、色带圆角）统一 **4 pt** 半径；**禁止**逐页改圆角造成方圆混乱。  
- **内边距**：卡片内文字与形状边缘保留 **统一内边距**（建议垂直方向 **≥ 页面标题字高 × 0.5**；多列卡片 **列间距相等**）。  
- **色带 / 高亮条**（结论条、摘要条）：底可用 **accent1 的浅 tint** 或 **`#E6F9B4` 类低透明洗**；条内正文用 **`#050B14` 或 `#196B24`**。**禁止**在 **饱和 `#B2ED1D` 满铺条** 上再叠浅色字（对比不足）。  
- **对比双栏**：左右容器 **底对齐或同高**；弱化侧：**浅灰底 + `tx1` 约 40–55% 不透明字**；强调侧：**浅绿洗底 + 深字**，可加 **accent1** 小图标（如勾选）。  
- **KPI 数字块**：数字可用 **极大字号** + **accent2（`#73B200`）** 或 **tx1**（白底）；说明标签用 **小一号 IBM Plex Sans / IBM Plex Sans SC Regular**；同一版式内 KPI 块 **宽高一致**。  
- **阴影**：默认 **无阴影**；若需轻微层级，仅用 **低透明度、小偏移、单一层** 外阴影，**禁止**多层强阴影。  
- **卡片内小标题**：仍用 **IBM Plex Sans Medium / IBM Plex Sans SC Medium**，字号须 **比页面顶栏标题至少小 4–6 pt**，层级清晰。

## 6. 可访问性与投影

- **对比度**：`#B2ED1D` 上避免叠 **白字**（对比不足）；绿底请配 **`#050B14` 或 `#196B24` 深字**。  
- **最小字号**：投影场景正文 **不小于 14 pt**；脚注不低于 **10 pt** 且仅作非关键信息。  
- **动画**：路演稿默认 **切页无动画** 或仅 **淡入**；禁止复杂飞入。

## 9. HTML 形态交付与资源内嵌

当同一套演示需以 **HTML** 呈现（例如单页摘要、内嵌预览、邮件或协作工具中的只读页面）时，须保证**打开方在未挂载你本机磁盘**的情况下仍能完整看到画面与配图；适用于一切从演示稿衍生出的网页形态交付。

- **截图与位图**：一律**内嵌进 HTML**（例如 `img` 使用 **`data:` URL（Base64）** 或等价内联方式），使单文件或可托管的片段自包含；**禁止**依赖仅在你电脑上存在的路径。  
- **本地资源**：**不得**使用 `file://`、相对路径（如 `./assets/…`、`../img/…`）或绝对本机路径（如 `/Users/…`、`C:\…`）引用图片、字体或其它静态文件——他人打开、转发或离线预览时会**断图、断样式**。若必须外链，应使用**可公开访问的 HTTPS URL**（经权限与品牌审核），而非「我机器上的某文件夹」。  
- **与 PPT 工作流的关系**：从 Masterdeck 导出 PNG 再用于 HTML 时，导出文件在入库或分享前应先**编码内嵌或上传至约定 CDN**，再在 HTML 中引用**稳定 URL**或 **data URI**；不要把 HTML 里写成「指向我桌面上的导出目录」。  
- **体积与格式**：截图优先 **PNG / WebP**；Base64 会增大 HTML 体积，邮件或 IM 有大小限制时需压缩图或改用上一条的托管链接，但仍**避免**本地路径。
