# 宣传物料模版

源文件在 Figma「Tier0 设计素材」，这里记录尺寸、结构和中英文版的差异；预览图在 `previews/`。名片在门户「品牌资产」页里可以直接编辑和导出。

## 名片

- 画板 1052 × 662（约 89 × 56 mm，300 dpi），正反两面，中英各一套。
- 正面（信息面）：暖白底 + 浅点阵；左上 T0 标记，右上姓名（品牌绿，600）和职位（灰），右上角个人二维码；下方四行信息，左列标签 `A.` `E.` `W.` `P.`（灰），右列内容。
- 背面（品牌面）：`#050B14` 底 + 暗点阵；左上 18px 品牌绿方块，右上网址，左下大号 Logo（品牌绿版），右下标语：英文「Factory app that fit」，中文「工厂软件工厂造」。
- 中文版地址一行写完；英文版地址可两行。网址按语言用 `www.tier0.cn` / `www.tier0.app`。

## 社媒方图（Builder 广告组）

- 1200 × 1200，一组 5 张：问题 → 描述 → 结果 → 应用场景 → 行动号召；中英各一组，画面相同，只换文字。
- 暗底，真实场景照片或产品界面做主视觉；左上 Logo、右上网址，或 Logo 和网址放在左下。
- 标题两行：英文用首字母大写（Title Case），把关键词或第二行设为品牌绿；中文同样只把关键词或一行设为品牌绿。
- 最后一张是行动号召：输入框样式的产品画面 + 一句说明 + 右下角行动链接（英文「Start free now →」，中文「免费开始 →」）。

## 长图（产品介绍）

- 宽 1745（英文）/ 1342（中文），高 8875，竖向排 6 张暗色卡片：封面 → 交付快 → 成本与回报 → 可扩展 → 全球部署 → AI Ready。
- 每张卡片：两行大标题（一行白、一行品牌绿）→ 两段说明（关键词加粗）→ 一张说明图（层级树、对比卡、图标阵列、地图、等距插图）。
- 封面放产品界面截图、副标题和网址，右下角「Continue →」按钮样式。

## 三折页

- 6 个面，中英各一套；内页白底、封面和中间页 `#050B14` 底。
- 内页结构：编号 + 分类（如「01 ｜ 挑战」，品牌绿小字）→ 标题 → 说明图 → 正文 → 品牌绿浅底的结论块（斜体或粗体）→ 底部要点标签。
- 封面：右上 Logo，大标题后三行用品牌绿列出「更快 / 更省 / 更开放」，下方等距方块插图。
- 封底：标语 + 两段定位说明 + 左下邮箱和网址 + 右下二维码。
