# 工厂产品广告母版

适用于 Builder、工厂 Agent、WorkBuddy、数据集成与 UNS、工业本体。以一个业务主题为单位制作中文黑版、中文白版、英文黑版、英文白版。先完成一组，再扩展下一组。

[黑版可编辑母版](https://www.figma.com/design/msabW3Xudtn6cCtdsxE7g2/?node-id=6126-37257) · [白版可编辑母版](https://www.figma.com/design/msabW3Xudtn6cCtdsxE7g2/?node-id=6140-8)

## 制作顺序

1. 从对应语言的审定 PDF 提取标题、说明、标签、示例数据和行动按钮，保留工单号、动作顺序和执行条件。英文以英文稿为准。
2. 复制同主题母版。横版为 1280 × 720，左侧标题和说明，右侧配图。四张 1200 × 1200 轮播依次讲产品用途、具体例子、可用场景和下一步行动。以原稿指定的页序为准。
3. 横版四个标签作为一组对齐左下，横版边距 48 px，方图边距 60 px。网址靠右，有注册按钮时按钮贴右边距，网址在按钮左侧，相距 32 px，两者垂直居中。网址用 IBM Plex Sans Regular 26 px，中文用 www.tier0.cn，英文用 www.tier0.app。
4. 英文标题用 IBM Plex Sans，自然字距。深浅版沿用对应母版的小点阵、网点照片及曝光。白版信息卡用纯白，标题强调用 #73B200。黑版用可辨识的半透明深灰卡面、细描边及少量绿色图标。配图外框四边完整。
5. 业务连接线统一 2 px，端点接到对象边缘。同组并列卡按最长内容统一宽度，卡高按内容和内边距确定。翻译后重新测量、换行、居中和连接。

## 按含义选择配图

| 主题 | 配图如何传达业务 |
| --- | --- |
| Builder | 需求旁展示可读的应用界面。优先使用与需求相符的真实截图，移除鼠标，其他业务的截图单独标明用途。 |
| 工厂 Agent | 半透明绿面、细边的等距主体连接现场数据与业务动作。需要确认的动作画出确认步骤。停机场景展示受影响的工单与工序。 |
| WorkBuddy | 用官方标志和连接器选择界面说明接入，用紧凑的提问和回复展示查询。 |
| UNS | 目录树解释工厂、产线、设备的层级，一张场景图可用中央文件夹连接使用同一数据的四种业务。 |
| 工业本体 | 用方盒表示业务对象，沿实际关系画出批次、工单和成品之间的追溯路径。 |

## 验收与交付

逐页对照原稿，在实际尺寸和缩略图检查标题、关键数据、图文含义、卡内空白、连线断点、重叠和安全边距。黑白版检查文字对比，中英文版检查版式对应。每个主题按语言和配色分别导出五页 PDF，第一页为横版，轮播 01 至 04 各占一页。文件按主题归档。
