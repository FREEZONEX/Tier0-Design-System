# 03-brand

对外：品牌资产。每一项都有自己的素材文件，结构相同：

```
<子目录>/
├── README.md   规范：怎么用、不能怎么用
└── assets/     源文件
```

| 目录 | 内容 |
|---|---|
| [`logo/`](logo/) | 标准版、反白版、单色版；最小尺寸、安全距离、错误用法；Logo 动效 |
| [`texture/`](texture/) | 点阵、网格纸等纹理源文件，以及强度上限 |
| [`animation/`](animation/) | 品牌动画：Logo 动画、转场、信号亮起的源文件与规范 |
| [`sound/`](sound/) | 声音 Logo、提示音、视频配乐方向 |
| [`imagery/`](imagery/) | 摄影风格、产品截图规范、示意图规范 |
| [`iconography/`](iconography/) | 图标绘制规范与图标库 |
| [`templates/`](templates/) | PPT、社媒、海报、名片、邮件签名，以及版式示例 |

颜色、字体、动效的数值和用法都在 `01-tokens`，这里只放带素材文件的品牌资产。
