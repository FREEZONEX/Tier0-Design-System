# 03-brand

对外：品牌识别与物料。每个子目录结构相同：

```
<子目录>/
├── README.md   规范：怎么用、不能怎么用
└── assets/     源文件
```

| 目录 | 内容 |
|---|---|
| [`logo/`](logo/) | 标准版、反白版、单色版；最小尺寸、安全距离、错误用法；Logo 动效 |
| [`color/`](color/) | 品牌色使用规则：Lime 绿的三种角色、配色示例（值来自 01-tokens） |
| [`typography/`](typography/) | 品牌排版：标题样式、版式示例、中英文混排规则 |
| [`texture/`](texture/) | 点阵、网格纸等纹理源文件，以及强度上限 |
| [`motion/`](motion/) | 品牌动效：Logo 动画、转场、信号亮起 |
| [`sound/`](sound/) | 声音 Logo、提示音、视频配乐方向 |
| [`imagery/`](imagery/) | 摄影风格、产品截图规范、示意图规范 |
| [`iconography/`](iconography/) | 图标绘制规范与图标库 |
| [`templates/`](templates/) | PPT、社媒、海报、名片、邮件签名 |

颜色、字体、动效等数值一律引用 `01-tokens`，这里只写品牌层面的使用规则。
