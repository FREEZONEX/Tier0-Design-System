# 网址与二维码

| 用途 | 中文 | 英文 |
|---|---|---|
| 官网 | `tier0.cn` | `tier0.app` |
| Tier0 Cloud Studio（产品入口） | `https://studio.tier0.cn/login` | `tier0.dev`（暂定） |
| 官网二维码 | [`qr-tier0-cn.svg`](qr-tier0-cn.svg) | [`qr-tier0-app.svg`](qr-tier0-app.svg) |

- 物料用哪种语言，就用同一种语言的网址和二维码，不混用：中文海报写 `tier0.cn`，英文海报写 `tier0.app`。
- 讲品牌、引导了解产品时放官网；引导注册、试用、登录时放 Cloud Studio 地址。
- 印刷物上网址写成 `www.tier0.cn` / `www.tier0.app`，不带 `https://`。
- 二维码保持白底黑码和四周留白（静区），不改颜色、不加 Logo、不裁切；最小印刷尺寸 2 cm。
- 机器读取用 [`links.json`](links.json)。
