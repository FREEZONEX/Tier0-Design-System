产品后台.

高密度工业工作台。IBM Plex，近黑主按钮，绿色只做状态与选中。下面是调用方法；再往下是组件样式与场景预览。

怎么开始

打开规范 → 对话生成 → 落到产品工程
准备
打开本仓库，或产品工程里已有 @tier0/ui
流程
说清页面目标，按产品后台规范生成界面
耗时
大概 10 分钟
产出
工作台页面（React / HTML）+ token 用法
  1. 01

    打开规范

    在 Cursor / Codex 里打开本仓库，或点名 surfaces/tier0-product/ 与 tokens/product.css。不要从官网 / PPT 抄字体和主按钮色。

  2. 02

    说清要做什么页

    写清页面目标、表格字段、关键操作。用产品后台场景：近黑主按钮，绿色只做状态与选中。

  3. 03

    生成后落到工程

    对照本页预览验收；有 monorepo 时优先用 packages/theme / packages/ui，少写死颜色值。

按 Tier0 产品后台规范做 Namespace 列表页：左侧导航 + 主区表格 + 近黑 Create 按钮。绿色只做状态，不要营销 Hero。先读 surfaces/tier0-product 和 tokens/product.css。
