交付到 Framer

适合资源列表、公告、更新日志与文档目录。使用 tier0-framer-page。

构建与验收

  • 修改 src 数据、文案与样式，构建生成 .tsx 和 preview.html；不手改生成文件。
  • 透明画布、4px 圆角、细边框、无阴影，语言跟随站点。
  • 容器查询适配 1440 / 730 / 390，验证中英 SSR、hydration、筛选展开与溢出。

放进 Framer 的三步

  1. Assets → Code → New code file，粘贴整份 .tsx。
  2. 拖到页面，各断点宽度 Fill、高度 Fit Content。
  3. Language 默认 Auto，按页头调整 Nav offset；外层已有边距时 Side padding 设 0。

使用代码组件，不是 Embed。

使用 tier0-framer-page，把这些公告做成可筛选、可展开的 Framer 页面。跟随站点语言，用容器查询适配三个断点。只改源文件，build + verify 后交付 .tsx、HTML 预览与安装说明。
