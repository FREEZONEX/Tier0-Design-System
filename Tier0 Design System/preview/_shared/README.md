# 共享 Token 预览

各 HTML 卡片演示 `tokens/core.css` 中的**原子 token**，三场景通用。

引用：`../../tokens/core.css`

## 文件

| 文件 | 内容 |
|------|------|
| colors-brand / neutrals / semantic | 色板 |
| type-display / headings / body | 字号 |
| spacing-scale, radii, shadows | 布局 token |
| buttons.html | 通用按钮（偏营销色，见说明） |
| inputs, cards, table, labels-tags, icons | 基础组件（产品 Carbon） |
| [icons-lucide.html](icons-lucide.html) | Lucide 选标索引（官网 / PPT） |
| hero-dark, logo-dark, flow-diagram | 品牌/深色 |
