# PPT — 审核清单

（摘自 [`sources/spec.marketing-deck.ppt.md`](../../sources/spec.marketing-deck.ppt.md) §7）

1. [ ] 主题色与文档 HEX 一致；蓝色仅 `#1D77FE` 及透明度变化  
2. [ ] 白底页顶栏：**Plex Sans/SC Medium**；封面主标题：**Poppins**；内容页标题 **不用 Poppins**  
3. [ ] 深色章节与封面共享深底；页脚仅 Tier0 版权行（无母公司条）  
4. [ ] 标题与正文字号级差 ≤3 级（图表内小字除外）  
5. [ ] accent1 不铺满大段背景  
6. [ ] 字体仅在白名单五族；中文均为 **IBM Plex Sans SC**  
7. [ ] 深色章节标题为 **Tektur Regular**（非 Bold 冒充）  
8. [ ] 配图：等轴、线宽一致、accent1 局部上色（§5.5）  
9. [ ] 卡片：白底对比、圆角 4pt、绿条字色、阴影克制（§5.6）  
10. [ ] HTML 交付无本地路径（§9）  
11. [ ] 全稿无 **FREEZONEX** 字样 / Logo / 口播归属（仅 Tier0）
