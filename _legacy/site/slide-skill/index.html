PPT / 讲解 HTML.

把大纲、文档、截图整理成品牌演示稿。同一份 deck.json 产出可改字的 PPTX，和可投屏讲解的 HTML。只做演示稿，不做产品 UI。

怎么开始

先一键安装 → 再对话生成
准备
本机有 Git + Node 18+；一行命令装到 Cursor / Codex
流程
先填交付表单，再让 Agent 生成稿
耗时
生成整稿大概 7–10 分钟
产出
可投屏的 HTML，和可改字的 PPTX（可只要一种）
  1. 00

    一键安装到本机

    终端粘贴下面一行。会装依赖，并链到 Cursor / Codex（以及 Claude / Agents）的 skills 目录。

    curl -fsSL https://raw.githubusercontent.com/FREEZONEX/Tier0-Design-System/main/skills/tier0-slide-skill/scripts/install-skill.sh | bash
  2. 01

    打开 Skill，让 Agent 开表单

    安装后新开对话，在 Cursor / Codex 里 @tier0-slide-skill，让 Agent 打开 PPT 交付表单。

    @tier0-slide-skill 帮我打开 PPT 交付表单（intake）入口，我要先填交付格式和素材再生成稿。
  3. 02

    填完交付表单

    打开表单 ↗

    说清楚要 HTML、PPTX 还是两者，补上封面信息和素材，确认后继续对话生成。

  4. 03

    把材料丢给 Agent

    附上大纲、旧 PPT、截图或架构图。需要 HTML + PPTX 时，从一开始就按双格式走，不要先做完一套再手工复制另一套。

  5. 04

    拿到稿并检查

    HTML 适合现场翻页讲解；PPTX 适合发给客户改字。在本页 Demo 里预览效果，要改某一页直接在对话里说。

用 tier0-slide-skill 做一份 Tier0 产品介绍 PPT：8 页，突出 UNS 与 Builder，交付 HTML + 可编辑 PPTX。先填交付表单；逐页写清本页目的和核心观点，再按 Layout Gallery 做疏密排版；没有证据的 KPI 不要写。
