# 图标与插画

## 按场景选库

| 表面 | 图标库 | 实现 |
|------|--------|------|
| **产品 UI** | Carbon 风格（mono-line） | `ui_kits/tier0-product/Icons.jsx` · `preview/_shared/icons.html` |
| **官网、PPT、HTML 原型** | **[Lucide](https://lucide.dev)** | [icons-lucide.md](icons-lucide.md) · `preview/_shared/icons-lucide.html` |

## 产品 UI（Carbon）

- 16 / 18 / 20 / 24px，1.5–2px 描边  
- CDN 参考：`https://unpkg.com/@carbon/icons/svg/32/<name>.svg`

## Lucide（官网 / PPT）

见 **[icons-lucide.md](icons-lucide.md)** — 引用方式、按位置选标、**带 Icon 卡片**规格。

## 禁止（全场景）

- Emoji 作 UI 图标  
- Unicode `✓` 代替勾选 SVG  
- 同一页混用两套图标库  

## 插画（共享方向）

- 等轴测、细线工业设备图  
- 黑/灰结构线 + `#B2ED1D` 数据流高光  
- 无 stock 摄影、无厚重 3D  

PPT 主视觉细则见 `surfaces/ppt/README.md`。
